Probability

Probability is the mathematical language of uncertainty. Grounded in set theory and measure theory, it provides the foundation for statistics, machine learning, information theory, and every rational approach to inference.

Sample Spaces and Events

Definition — Sample Space

The sample space Ω\OmegaΩ is the set of all possible outcomes of a random experiment. An event is any subset A⊆ΩA \subseteq \OmegaA⊆Ω.

Ω={H,T}\Omega = \{H, T\}Ω={H,T}

Since events are sets, set operations apply: A∪BA \cup BA∪B is the event that AAA or BBB occurs; A∩BA \cap BA∩B is both; AcA^cAc is the event that AAA does not occur.

Kolmogorov's Axioms

Andrey Kolmogorov (1933) placed probability on a rigorous axiomatic foundation. A probability measure is a function P:F→[0,1]P : \mathcal{F} \to [0,1]P:F→[0,1] satisfying:

1.

Non-negativity

P(A)≥0 for all events AP(A) \geq 0 \text{ for all events } AP(A)≥0 for all events A

2.

Normalization

P(Ω)=1P(\Omega) = 1P(Ω)=1

3.

Additivity

P(A∪B)=P(A)+P(B) if A∩B=∅P(A \cup B) = P(A) + P(B) \text{ if } A \cap B = \emptysetP(A∪B)=P(A)+P(B) if A∩B=∅

From these three axioms, all of probability theory follows. Key consequences:

P(∅)=0P(Ac)=1−P(A)P(A∪B)=P(A)+P(B)−P(A∩B)P(\emptyset) = 0 \qquad P(A^c) = 1 - P(A) \qquad P(A \cup B) = P(A) + P(B) - P(A \cap B)P(∅)=0P(Ac)=1−P(A)P(A∪B)=P(A)+P(B)−P(A∩B)

Conditional Probability

Definition — Conditional Probability

The probability of event AAA given that event BBB has occurred (with P(B)>0P(B) > 0P(B)>0):
P(A∣B)=P(A∩B)P(B)P(A \mid B) = \frac{P(A \cap B)}{P(B)}P(A∣B)=P(B)P(A∩B)​

Conditioning restricts the sample space to BBB and re-normalizes. The multiplication rule follows directly:

P(A∩B)=P(A∣B) P(B)=P(B∣A) P(A)P(A \cap B) = P(A \mid B)\, P(B) = P(B \mid A)\, P(A)P(A∩B)=P(A∣B)P(B)=P(B∣A)P(A)

Independence

Definition — Independence

Events AAA and BBB are independent if knowing BBB occurred gives no information about AAA:
P(A∩B)=P(A) P(B)equivalently,P(A∣B)=P(A)P(A \cap B) = P(A)\, P(B) \qquad \text{equivalently,} \quad P(A \mid B) = P(A)P(A∩B)=P(A)P(B)equivalently,P(A∣B)=P(A)

Independence and mutual exclusivity are very different concepts. If P(A)>0P(A) > 0P(A)>0 and P(B)>0P(B) > 0P(B)>0, then AAA and BBB cannot be both independent and mutually exclusive.

Bayes' Theorem

Theorem — Bayes

P(A∣B)=P(B∣A) P(A)P(B)P(A \mid B) = \frac{P(B \mid A)\, P(A)}{P(B)}P(A∣B)=P(B)P(B∣A)P(A)​
Using the law of total probability to expand the denominator:
P(A∣B)=P(B∣A) P(A)P(B∣A) P(A)+P(B∣Ac) P(Ac)P(A \mid B) = \frac{P(B \mid A)\, P(A)}{P(B \mid A)\,P(A) + P(B \mid A^c)\,P(A^c)}P(A∣B)=P(B∣A)P(A)+P(B∣Ac)P(Ac)P(B∣A)P(A)​

Bayes' theorem is the engine of Bayesian inference: it tells us how to update a prior belief P(A)P(A)P(A) in light of new evidence BBB to obtain a posterior P(A∣B)P(A \mid B)P(A∣B).

Classic example: a medical test for a disease with 1% prevalence. Sensitivity (true positive rate) = 99%, specificity (true negative rate) = 95%. If you test positive, Bayes' theorem gives P(disease∣+)≈16.7%P(\text{disease} \mid +) \approx 16.7\%P(disease∣+)≈16.7% — far lower than intuition suggests, because the disease is rare.
