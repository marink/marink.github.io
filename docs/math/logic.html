Logic

Mathematical logic is the study of formal reasoning — the rules by which conclusions follow necessarily from premises. It underlies every proof in mathematics and every program in computer science.

Propositions

A proposition is a declarative statement that is either true or false, but not both. We denote propositions with letters like p,q,rp, q, rp,q,r and their truth values with TTT (true) or FFF (false).

"7 is prime" — proposition (true). "x + 1 = 5" — not a proposition (truth depends on x). "Read this!" — not a proposition (imperative).

Logical Connectives

Propositions are combined using connectives to form compound propositions:

¬p\lnot p¬p
Negation
True when p is false.
p∧qp \land qp∧q
Conjunction
True when both p and q are true.
p∨qp \lor qp∨q
Disjunction
True when at least one is true.
p→qp \to qp→q
Implication
False only when p is true and q is false.
p↔qp \leftrightarrow qp↔q
Biconditional
True when p and q have the same truth value.

The implication p→qp \to qp→q is often the most counterintuitive: a false hypothesis makes the whole statement vacuously true. "If the moon is made of cheese, then 2+2=5" is a true implication.

Logical Equivalence

Definition — Logical Equivalence

Two propositions PPP and QQQ are logically equivalent, written P≡QP \equiv QP≡Q, if they have identical truth values for every assignment of truth values to their variables.

Key equivalences

Double Negation

¬¬p≡p\lnot\lnot p \equiv p¬¬p≡p

Contrapositive

(p→q)≡(¬q→¬p)(p \to q) \equiv (\lnot q \to \lnot p)(p→q)≡(¬q→¬p)

De Morgan 1

¬(p∧q)≡¬p∨¬q\lnot(p \land q) \equiv \lnot p \lor \lnot q¬(p∧q)≡¬p∨¬q

De Morgan 2

¬(p∨q)≡¬p∧¬q\lnot(p \lor q) \equiv \lnot p \land \lnot q¬(p∨q)≡¬p∧¬q

Implication

(p→q)≡(¬p∨q)(p \to q) \equiv (\lnot p \lor q)(p→q)≡(¬p∨q)

Absorption

p∨(p∧q)≡pp \lor (p \land q) \equiv pp∨(p∧q)≡p

A proposition that is always true is a tautology (e.g. p∨¬pp \lor \lnot pp∨¬p). One that is always false is a contradiction (e.g. p∧¬pp \land \lnot pp∧¬p).

Predicate Logic

Propositional logic treats propositions as atomic. Predicate logic (first-order logic) adds variables, predicates, and quantifiers — allowing statements about entire domains.

A predicate P(x)P(x)P(x) is a proposition-valued function: P(x)=“x is prime”P(x) = \text{``}x \text{ is prime''}P(x)=“x is prime” is true for x=7x=7x=7, false for x=9x=9x=9.

"Not all integers are even" is the same as "there exists an integer that is not even."

Rules of Inference

A rule of inference is a valid argument form — a pattern that guarantees the conclusion is true whenever the premises are true.

Modus Ponens

p,p→q  ⊢  qp,\quad p \to q \;\vdash\; qp,p→q⊢q

Modus Tollens

¬q,p→q  ⊢  ¬p\lnot q,\quad p \to q \;\vdash\; \lnot p¬q,p→q⊢¬p

Hypothetical Syl.

p→q,q→r  ⊢  p→rp \to q,\quad q \to r \;\vdash\; p \to rp→q,q→r⊢p→r

Disjunctive Syl.

p∨q,¬p  ⊢  qp \lor q,\quad \lnot p \;\vdash\; qp∨q,¬p⊢q

Addition

p  ⊢  p∨qp \;\vdash\; p \lor qp⊢p∨q

Simplification

p∧q  ⊢  pp \land q \;\vdash\; pp∧q⊢p

The symbol ⊢\vdash⊢ means "therefore." Modus Ponens is the most fundamental rule: if we know ppp is true, and we know p→qp \to qp→q, we can conclude qqq.
